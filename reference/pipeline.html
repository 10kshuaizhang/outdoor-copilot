分析管道速查

打印友好的一页纸：从文件到报告数字。

入口

parseGpx(xml) → TrackPoint[]
analyzeRoute({ points, profile?, weather?, plannedStart? }) → RouteAnalysis

管道（顺序固定）

  1. 距离 / 爬升 / 中心点（geo.ts）
  2. 自适应分段 + 海拔剖面（segments.ts）
  3. Base 分项（baseDifficulty.ts）
  4. 天气调整分数与时长因子（weatherAdjust.ts）
  5. 时长种子 → 生理负荷层（physiology.ts）
  6. 个人化（personalize.ts）→ Personal Difficulty
  7. 最终时长区间（再乘天气因子）
  8. 挑战路段 + 出发建议（challenges.ts）
  9. 模板 explanation（UI 可选再调 /api/explain）

硬规则

分数、时长、挑战公里段只来自确定性引擎。 LLM 只能解释，不能创造关键数据。

仓库地图

src/lib/engine/     ← 计算核心（可 Node 单测）
src/app/analyze/    ← 交互编排
src/app/api/weather ← Open-Meteo 代理
src/app/api/explain ← 可选 LLM 润色
src/lib/history/    ← 本机存储
src/lib/share/      ← 分享摘要
