术语表

全课共用词汇。释义以仓库 Spec 与实现为准。

核心概念

Base Difficulty
路线本身的基础负荷（0–100），不含个人档案调整；可含天气与生理参考层对分数的贡献。
Personal Difficulty
在 Base 之上按经验、舒适距离/爬升、风险偏好等调整后的「对你」难度。
分析缝 / Seam
唯一公共计算入口 analyzeRoute(input) → RouteAnalysis；页面与测试都经此调用。
贡献项（contributions）
可解释的加减分条目（code / label / delta），构成 Why，而非黑盒一句话。
置信度（confidence）
系统对当前结果把握程度；档案不全、天气 fallback 等会压低。
档位（band）
分数映射的中文标签：轻松 / 适中 / 吃力 / 很难 / 不建议。

数据与边界

GPX
GPS Exchange Format：轨迹 XML；本产品解析为 TrackPoint[]。
模板解释
引擎生成的中文说明；始终可用。LLM 仅可润色文案，不得改数字。
Fallback 天气
Open-Meteo 失败时的中性天气假设，保证报告仍可出。
